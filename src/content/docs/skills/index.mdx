A [skill](https://code.claude.com/docs/en/skills) is a folder of instructions that Claude loads when the task matches it. Until then, only its short description sits in Claude's context, so GAIA can ship detailed guidance without filling every session.

GAIA ships skills in two places: the React app's in `apps/web/.claude/skills/`, which load in sessions working on the app, and project skills in `.claude/skills/`, which apply anywhere in the repository.

## How triggering works

Each skill's description lists the phrasings and situations that load it. Claude loads a skill when its description fits the task, whether the task comes from you, from work Claude or a sub-agent is already doing, or from another skill or rule that points to it. "Scaffold a card called price-card" loads `new-component`; "this useEffect fires twice" loads `react-code`.

`/gaia-wiki`, `/update-deps`, and `/update-gaia` are skills, so asking in plain language starts them too. The [statusline](/workflow/statusline/#nudges) shows them (`🧠`, `📦`, `🚀`) when they have work to do.

Some commands are yours to type: `/gaia-init`, `/setup-gaia`, `/gaia-fitness`, `/gaia-forensics`, `/gaia-codify`, and `/gaia-residue`. Claude never starts them, even when you ask in plain language. The one exception: `/gaia-init` runs `/setup-gaia` as its last step.

## Questions are menus

When a GAIA skill or command needs you to choose, it shows a menu with the recommended option first. GAIA's `user-questions` rule holds the skills you write to the same standard, and its `fenced-copy-paste-blocks` rule puts anything meant for you to paste in its own code block, so Claude Code shows a copy button.

## Adding your own

Ask Claude to write the skill for you:

```text
Create a skill that <what it should help with>. It applies to <the whole repository | only the frontend app>. Write a description that names the phrasings that should trigger it.
```

To always run the skill on a particular model, say which one in the same request. Claude picks up the new skill in the next session, and [`/gaia-fitness`](/maintenance/fitness/) checks it.
