GAIA records every model call in a local usage ledger (a log file) and shows what your work cost, always in the same form: tokens, dollars, elapsed time, and active time.

:::tip[Your data stays on your machine]
The ledger stays on your machine and is never sent anywhere. Working out the price does not use the network either. It is yours to read and use however you like.
:::

The ledger is `.gaia/local/telemetry/usage.jsonl` in the main checkout. Every worktree writes to the same file, and GAIA never deletes it.

## What you see

A single cost prints as one line:

```text
Cost: 5.2M tokens, $3.41, 14m2s (6m39s active)
```

Two or more print as a box:

```text
SPEC-NNN Cost

+--------------------------------------------------------+
|  Spec: 40.9M tokens, $26.15, 1h4m12s (31m52s active)   |
|  Plan: 46.7M tokens, $23.09, 1h12m40s (48m19s active)  |
+--------------------------------------------------------+
| Total: 87.6M tokens, $49.24, 2h31m5s (1h20m11s active) |
+--------------------------------------------------------+
```

Rows are rounded to 0.1M tokens and to the cent, and the Total adds up the rounded rows.

Each row shows two times:

- **Elapsed time** runs from a run's first model call to its last, including pauses while you read, answer, or step away. The Total's includes gaps between runs, so it can be longer than the rows added together.
- **Active time**, in parentheses, is the part of that span when Claude was working. The Total counts work two rows share only once, so it can be shorter than the rows added together.

### How active time is counted

- **Your turns** run from your prompt to Claude's last piece of work before your next one, minus time waiting for you to answer a question or approve a plan.
- **Sub-agents and headless runs** count as one stretch, first piece of work to last.
- **Overlap**: sessions and sub-agents running at the same time count once.

Some idle time still counts: a turn left open with no question pending, a long-running tool, your machine sleeping mid-turn, or a question Claude asks in plain text instead of its question prompt.

Spend recorded without activity data has no active time. A row that mixes both reads as a minimum, such as `(6m39s+ active)`. A row with none leaves the parentheses out.

### Where it prints

- **Every merge Claude runs** prints a `PR #<N> Cost` box: **Execute** (the work on the branch), **Audit** (what the Code Audit Team spent), and **Total**.
- **`/gaia-plan`** from a SPEC ends with a box of **Spec**, **Plan**, and **Total** rows; `/gaia-spec`'s run is the Spec row. A plan without a SPEC ends with a Cost line. When the plan's work merges, it prints the whole cost from SPEC to merge, with an **Execute** row.
- **`/gaia-fitness`, `/gaia-cleanse`, `/gaia-codify`, `/gaia-debt`, `/gaia-residue`, `/gaia-forensics`, `/gaia-wiki`, `/update-deps`, and `/update-gaia`** end with a Cost line. `/gaia-wiki`'s includes the wait for its pull request to merge.

A box with only one row that cost anything prints as a single line.

### Notes under the figures

A `Note:` line under the figures tells you when a figure is not the full picture:

- Usage was still being saved when it was read, so the figures may be low (the note names the command that shows the final numbers).
- A model has no price, so the cost is a minimum, and that row reads `at least $X.XX`.
- A run recovered after an interruption counts only one session.
- Some spend has no activity data, so an active time marked `+` is a minimum.

The merge's `PR #<N> Cost` box shows these as lines starting with `!` instead.

The audit's [code review](/workflow/code-audit-team/#the-code-review) runs as its own session, so its cost can reach the ledger after the merge and be missing from the box. The pull request's `## Audit rounds` section shows what it cost.

When nothing can be priced, the price reads `cost unavailable`. A figure is never made up.

## What an idea cost

Ask Claude what one piece of work cost, from its first research to its merge, across every session, including ones resumed after `/clear`. You can ask about a SPEC (`SPEC-012`), a plan (`PLAN-004`), an issue (`#142`), or a research topic:

```text
What did SPEC-012 cost, from first research to merge?
```

```text
Show the total cost of issue #142 as a box.
```

A branch's cost is counted toward its piece of work automatically when the branch name includes it (`debt/142-...`, `fix/142-...`, a SPEC's plan branch). Otherwise ask Claude to link it once:

```text
Count the cost of branch <branch> toward the research on <topic>.
```

Costs from before the ledger's first entry are not recorded.

## Prices

Prices come from the rate table that ships with GAIA, `.gaia/scripts/token-rates.json`, which covers current Claude models. New versions arrive through `/update-gaia`. Prices are applied each time figures are shown, not stored, so a corrected rate changes every past figure the next time you look.

To set your own prices, or add a model the table does not have, ask Claude to write a price override for you:

```text
Use my own token prices: <model id> at $<input> per million input tokens and $<output> per million output tokens.
```

Claude writes them to `.gaia/local/telemetry/token-rates.override.json` in the main checkout. The file looks like this:

```json
{ "models": { "claude-opus-5-5": [ { "input": 4, "output": 20 } ] } }
```

Prices are dollars per million input and output tokens. Each model you list replaces its shipped rates; the rest keep theirs. An invalid file is ignored, and each cost readout says so. GAIA never deletes it.
